Mobile · v1 for reviewOwner, staff and karigar

Digital Darzi — mobile app redesign

Screen designs for review. Every screen uses data the API already returns; yellow notes name the source and any backend gap.

Designed under these assumptions (from BUSINESS_WORKFLOWS §6)
  • Garment types stay the fixed list. Templates are the owner's "styles" inside a garment.
  • Staff have a display-only designation (Master, Cutter, Helper). Permissions come from the role. Needs small backend change M6.
  • Measurements taken during an order are saved to the customer by default.
  • Karigars see no prices. Their app shows only their own work.
  • Super Admin works on the web console, not this app.
